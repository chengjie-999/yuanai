# 本地终端愿景设计：无凭证本地终端（yuan）+ 本机执行现场（2026-11-15 立项；2026-11-15 修正——「网站桌面客户端」表述与主入口定位相悖，yuan=无凭证用户的本地终端）

## 1. 定位回顾：终端在愿景中的角色

产品愿景（最高优先级，见 product-positioning）：**数据分析为核心 + 手机定计划、电脑执行**，对话是统一入口。

| 端 | 角色 | 形态 |
|----|------|------|
| 网站（手机/平板） | 制定计划、发指令、看进度——任何地点 | 移动优先 |
| **本地终端（电脑）** | **执行现场**：任务进来的入口、执行过程可见、结果回流 | 桌面形态，模仿 CC |
| 桌宠（电脑） | 陪伴与状态可视化 | 六态联动 |
| 后台/API | 管理面 | — |

终端的三重身份（历次拍板沉淀，全部保留、互不冲突）：
1. **无凭证用户的本地终端**（2026-11-15 用户拍板修正）：平台云端为模型层、可访问云端会话（cc = CC 窗口、/chat = 小元窗口、双向同步）——**不是「网站桌面客户端」**；主对话入口唯一=网站/移动端
2. **本机执行现场**（云边协同）：网站来的任务由本机 Agent/CC 执行，工具行实时可见 + 观测右栏
3. **专业模式**（/local，v2 遗产）：CC 同款本机直连（SDK、仓库锁、审计），开发者形态

一句话：**终端 = 网站的桌面窗口，CC 的形态，电脑执行的可视化现场**。

## 3. 差距 → 路线（P0-P2 全部云端+终端复用，无新迁移）

### P0 消息同步闭环（用户实测「消息同步没有」的另一半）
- **问题**：终端发的消息网站已可见（/chat/save 同链路 ✅）；但**网站发的消息终端看不到**——只有切换会话/重进才加载，没有轮询
- **方案**：终端 15s 增量轮询当前窗口会话（复用网页多端同步 P0-1 同款机制）：
  - chat_client 增 `load_messages_incremental(sid, fingerprint)`：/chat/messages 已支持（条数,末条哈希）指纹——指纹一致跳过；有新消息且无进行中 SSE → 按 msg_id 去重尾部合入（迁移 0032 msg_id 幂等基建已就绪）
  - 渲染层：合入后新增块上屏（贴底跟随）；自动朗读联动（终端无朗读，跳过）
  - 触发：15s 循环（并入现有观测轮询线程）+ /sessions 切换重置基线
- **验收**：手机发消息 → 终端 15s 内出现新气泡；双向一致

### P1 CC 窗口执行时间线形态（对齐网站 P2 视觉语言）
- **问题**：网站 CC 窗口是「执行时间线」（扁平块全宽灰底 + 左色条 + 操作行裁剪），终端 CC 窗口还是普通气泡——同一窗口两端形态不一致
- **方案**：renderer 增加 `exec_mode` 形态开关（/claude 与 /chat 两种窗口切换）：
  - exec 形态：块=全宽扁平 + 左色条（品牌棕），无「你 ▸」气泡、无身份标签重复（标签移到状态栏「CC 窗口」徽标）
  - 工具行/思考折叠/审批卡复用
- **验收**：终端 CC 窗口与网站 CC 窗口视觉同构（一段对话两端看起来是同一件事）

### P2 会话管理与委派呈现
- /sessions 列表加窗口类型徽标（CC 窗口/小元窗口/主对话★）
- `/new` 命令：按当前窗口新建会话（对齐网页「新对话」按钮语义）
- 主对话中的委派任务卡（META w/wk）：终端呈现为紧凑卡片 + 「已转 CC 窗口执行」提示（点击不可跳转——终端内用 /claude 查看）
- 状态栏窗口徽标：`claude` → 「CC 窗口」、`chat` → 「小元」中文显示

### P3（挂账，不排期）
- 流式 diff 高亮（任务 #18，网站同源——执行窗口改文件的 diff 可见）
- 桌宠 attention 联动扩展（approval 已在）

P0（约 0.5 天）→ P1（约 1 天）→ P2（约 1 天），全部终端+chat_client 改动，无后端新端点（/chat/messages 已有指纹协议），测试各 +N。打包批次统一收口（textual 资源/使用说明模板/#41 宿主句柄真机验证）。

## 6. 验收口径（愿景视角）

1. 手机在网站（CC 窗口/主对话）发消息 → **15s 内出现在电脑终端**，终端回复网站同样可见——两端是同一会话的两个窗口
2. 电脑终端打开 CC 窗口 = 网站 CC 窗口的执行时间线（同一视觉语言）
3. 终端无噪音：空闲只看到对话本身；一切按键/命令速查在 ? 浮层
4. /local 专业模式与网站完全隔离，互不污染
