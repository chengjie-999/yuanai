小元AI 本地 Agent —— 三步开始使用
================================

第 1 步：下载
  在网站登录你的账号，打开「本地 Agent」页（/chat/agent），
  点「下载默认版本」——浏览器会下载一个安装包（约 200MB）。

第 2 步：安装
  双击安装包 → 安装向导一路「下一步」（建议勾选「创建桌面快捷方式」）。
  安装完成后，电脑右下角任务栏出现「小元AI」彩色圆球图标，即安装成功。
  · 安装包文件名里已包含你的账号信息——双击安装后自动注册，
    全程不需要输入任何码。
  · 下载后请不要修改安装包文件名。

第 3 步：使用
  · 在网站对话时说「帮我分析数据」等任务，小元AI 会自动调用你电脑上
    的 Agent 执行（数据分析 / 数据采集 / 浏览器自动化 / Claude Code）。
  · 右键右下角小元AI 图标可查看：账号归属、能力开关、设置面板、检查更新。
  · 终端用户可安装命令：yuan（本机 Claude Code 终端）、yuancc（Claude Code 原生终端）。

常见问题
  · 提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」即可
    （软件暂未购买数字签名，属正常提示）。
  · 换新电脑：在网站「本地 Agent」页点「重新生成」拿新安装包，在新电脑
    安装即可；旧设备可在该页解绑。
  · 卸载：Windows「设置 → 应用」里找到「小元AI Agent」卸载；
    卸载时默认保留你的数据（确认删除才会清空）。
