# 小元AI 隐私政策

**更新日期：2026-10-29**

小元AI（下称「我们」）深知个人信息对您的重要性。本政策依据《中华人民共和国个人信息保护法》（PIPL）、《中华人民共和国网络安全法》、《中华人民共和国数据安全法》及《生成式人工智能服务管理暂行办法》等法律法规制定，向您说明我们如何收集、使用、存储、共享和保护您的个人信息，以及您享有的权利。

## 一、我们收集的信息

1. **账号信息**：您在注册/由管理员创建账号时提供的用户名、密码（加密存储）、昵称。
2. **使用信息**：您在使用本服务时主动输入、上传的内容（对话文本、图片、数据集、知识库文档等）。
3. **设备与日志信息**：IP 地址、访问时间、浏览器类型、设备信息、访问日志。
4. **本地 Agent 信息**：您自愿安装本地智能体时，本机生成设备标识（agent_id）并上传安装注册信息；本地 Agent 执行任务的工具名称等元数据会上报（**不含任务内容**）。

## 二、我们如何使用信息

1. 提供、维护和改进对话、数据分析、自动化等核心服务；
2. 生成对话标题、记忆整理等 AI 辅助功能（您的对话内容经模型处理）；
3. 内容安全审核、投诉举报处理、风险防控与合规审计；
4. 统计分析与安全防护（去标识化处理）。

## 三、信息存储与保护

1. **存储位置**：您的个人信息存储于中国境内的云服务器（火山引擎）与数据库服务中。
2. **保存期限**：为实现本政策目的所必需的期限内保存；您注销账号后，我们将依法在合理期限内删除或匿名化处理您的个人信息。
3. **安全措施**：传输加密（HTTPS/TLS）、访问鉴权（JWT/设备凭据）、数据库最小权限、接口限流、安全审计日志等技术与管理措施。

## 四、信息共享与第三方处理

我们仅在下列情形共享您的信息：

1. **模型服务商**：您输入的对话内容将发送至模型服务商完成推理（包括 DeepSeek、字节跳动火山引擎（豆包大模型）等境内服务商），相关第三方仅用于响应生成，不用于其自身模型训练（另有约定的除外）。
2. **语音服务**：您使用语音通话/朗读功能时，音频与文本经火山引擎语音服务处理。
3. **联网搜索/文献检索**：您使用联网搜索或 PubMed 文献检索时，检索关键词将发送至对应搜索引擎/NCBI（NCBI 为境外服务，仅当平台开启该功能时才会发生，且仅涉及检索关键词，不涉及其他个人信息）。
4. **法定情形**：依据法律法规、监管要求或司法程序向有权机关提供。
5. 除上述情形外，我们**不会**向任何第三方出售、出租您的个人信息。

## 五、您的权利

依据 PIPL，您有权：

1. **查阅、复制**：查看并复制您的个人信息（设置页「我的记忆」等入口）。
2. **更正**：发现信息不准确时更正。
3. **删除**：删除您的对话、记忆、知识库等个人内容；或通过**注销账号**行使删除权——注销后我们将级联删除您的账号、会话记录、记忆、数据集、知识星球、计划及本地设备绑定等信息。
4. **撤回同意**：停止使用相关功能或注销账号即视为撤回同意。
5. **申诉与咨询**：账号被冻结时可通过申诉入口提交申诉；对本政策或个人信息处理有任何疑问、投诉，可通过举报/申诉入口联系平台管理员。

## 六、未成年人保护

本平台服务面向成年人。我们不会有意收集 14 周岁以下未成年人的个人信息。如您为未成年人，请在监护人指导下使用本服务。

## 七、政策更新

本政策更新后将通过页面公告提示。重大变更（如处理目的、方式、范围变化）将提前通知并重新征得您的同意。

**联系与反馈**：通过平台「举报」按钮、账号申诉入口或向平台管理员反馈。
