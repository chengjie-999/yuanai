# 知识星球大融合愿景：AI 与人类共同打造的知识星球（2026-11-15 立项探索）

**来源**：用户拍板（2026-11-15）——「vault 跟记忆、文件管理、知识库有相似的地方，可合并成 AI 与人类共同打造的知识星球」；先根据成熟产品探索，作为未来愿景。本文档 = 三组产品调研（Notion/Coda、Obsidian 生态、AI 原生记忆产品）的综述 + 愿景形态 + 分阶段路线。

## 1. 现状四块能力（待融合）

| 能力 | 现状 | 角色 |
|------|------|------|
| 知识星球 | 星球→思维导图→线性笔记三级结构，Milvus 检索，导图导入 + AI 文章化，星空视觉 | 人定骨架的知识库 |
| 长期记忆 | facts.jsonl 条目化（只归档不删除），折叠/整理/自动整理，设置页可编辑 | AI 眼中的「关于用户的事实」 |
| 文件管理 | data/user_files 私有可写 + 服务器数据只读 | 原始素材 |
| Obsidian vault 双向同步 | 20s 轮询、三向冲突判定、本地 .md 落盘（菜单已下架，引擎保留） | 本地文件所有权入口 |

## 2. 成熟产品调研要点（2026-11，三组并行）

### 2.1 协作形态（Notion/Coda 系）
- **引用式问答**：统一检索 + 答案必带源链接 + 按权限过滤（Notion Enterprise Search/Q&A）
- **AI 字段自动填充**：人定义字段与提示词，AI 逐行摘要/分类/提取，源变更自动重算（Notion Autofill / Coda AI Column）——最稳的人机分工
- **可刷新 AI 块**：摘要不是一次性快照，源更新可刷新；对话产物直接落成页面/行（Coda AI Blocks）
- **Agent 显式记忆 + 可回溯**：指令页=记忆库；版本历史区分人/Agent 修改、一键回滚（Notion 3.x）
- **知识卫生**：Verified Pages（Owner + 有效期 + 过期提醒 + 搜索加权）解决知识腐化（Notion Wiki）

### 2.2 本地优先与安全边界（Obsidian 生态）
- **文件为王**：vault = 本地 .md 文件夹；反链 > 全局图谱；MOC 枢纽自下而上涌现
- **读写分层**：AI 默认只读检索（Smart Connections）；写先过 RAG 问答带出处，受控后才开写（Copilot V4）
- **元数据契约**：frontmatter + schema 约束——AI 按字段填、禁止发明
- **人类掌控写边界**：AI 输出进收件箱人工合并；diff 预览 + 一键撤销 + 软删归档；批量前存档点；规则=不删除只加结构
- **用户痛点实录**：AI 批量生成「看着完整却搜不到」（72.8% 生成后再未编辑）——AI 不掌握库的全局组织逻辑

### 2.3 记忆沉淀与写回提案（AI 原生记忆产品）
- **对话晋升知识**：AI 回答存只读 note，人转成 source 才进可信语料（NotebookLM）；研究线程固化成文档（Perplexity Spaces Pages）
- **记忆可见可改**：可管理、可看来源（ChatGPT Memory / Claude Memory 按 topic 编辑）
- **写回提案制**：agent 写入先进审核队列（Foundation/Vouch）；业界共识：**只审「推断」，用户原话等观察自动入**，防审批疲劳
- **反面教训**：Rewind 屏幕级全量采集停运；Mem 自动分组黑箱成「第二收件箱」——全自动组织不可取

## 3. 愿景形态（知识星球 v2）

> 一个以对话为入口、以星球为骨架、以本地文件为所有权载体的知识库——AI 负责检索、提炼、起草、巡检；人负责定结构、审内容、做终审。

**三条核心原则**（吸收全部调研共识）：

1. **分层不合表**：记忆=可变事实（AI 的工作记忆）、笔记=人工长文（人的作品）、文件=原始素材（不可篡改）、对话=来源（可回溯）。用统一 id + backlink 串联，Milvus 统一索引。
2. **AI 写回提案制**：AI 永远不直写人的正文——产出落「候选区」（AI 提议 + 来源引用 + diff 预览），人一键采纳/拒绝/回滚；用户原话等观察自动入档（防审批疲劳）。复用既有「只归档不删除」记忆纪律。
3. **文件为王 + 云边协同**：md 为唯一事实源，Milvus/文章化/记忆均为可重建派生层；vault 同步保留本地入口（文件系统级、停运无风险）；本地 Agent 执行结果（代码/分析/浏览器）可回流知识库——这是 Notion/Obsidian 都没有的。

**借鉴落地映射**：

| 借鉴（出处） | 落地形态 |
|------|------|
| 引用式问答（Notion） | 聊天回答挂「知识星球」来源标签可点回原文（已有雏形） |
| AI 字段自动填充（Coda） | 笔记自动生成摘要/标签/关联星球字段，源变自动刷新 |
| 对话晋升知识（NotebookLM） | 对话 → AI 候选笔记（摘要+聚类+来源）→ 人确认升为星球笔记 |
| 记忆可见可改（ChatGPT/Claude Memory） | 记忆条目带来源消息引用（现有 facts.jsonl 加 source 展示） |
| 知识卫生（Notion Wiki） | 笔记 Owner/复审周期/过期提醒（「已验证」徽章） |
| 收件箱 + 撤销（Obsidian 插件） | AI 候选区 + 采纳/拒绝/回滚 + 软删归档 |
| 反链 > 图谱（Obsidian） | AI 只做关联建议，低置信不自动建链 |
| 提案制只审推断（Foundation） | 原话观察自动入、推断内容人工审 |

## 4. 分阶段路线（建议，未排期）

- **P0 记忆可见化**：facts.jsonl 条目展示来源消息引用 + 设置页可点回对话——「记忆是 AI 的工作笔记」透明化（改动小，复用现有记忆卡）
  - **实践样板（2026-11-15 用户拍板「这次是 T6 很好的实践示例，可以借鉴」）**：文档渲染闭环（f5787d8 + 后续）——① 每条知识有**独立链接**（/api-docs?d=<slug>，刷新保持、可分享）② 来源引用**点击即跳转渲染形态**（markdown 内链接拦截，不再裸显源码）③ 统一**渲染视图**而非数据裸读。记忆条目的目标形态同构：记忆条目=可定位节点（独立 URL）、来源消息=可点击回对话、设置页=渲染而非 JSON
- **P1 对话沉淀候选区**：对话后 AI 生成候选笔记（摘要 + 来源 + 建议归属星球/导图节点）→ 人确认升为星球笔记/导图节点；候选区独立存储不污染正文
- **P2 笔记 AI 字段**：摘要/标签/关联自动填充 + 源变自动刷新（订阅笔记内容 hash）；「已验证」复审徽章
- **P3 vault 回归**：vault 同步作为「本地文件所有权入口」重新评估（P0-P2 的沉淀物均可落 vault），修复对话框线程问题或迁移到网页面板入口
- 挂账候选：知识卫生（Owner/复审周期）、AI 关联建议、本地 Agent 执行产物回流
