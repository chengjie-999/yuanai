# 小元AI 全面合规审计报告（2026-10-25）

> 审计范围：代码全仓静态审计（隐私链路 / AI 内容链路 / 许可证与爬虫 / 法规对照）+ 截至 2026-10 的中国 AI 合规法规检索。
> 本文为合规研究整理，不构成正式法律意见；备案/评估口径以国家网信办及属地省级网信办为准。

## 〇、总体判定（先回答「管不管得到我」）

| 判定项 | 结论 |
|---|---|
| 是否「向境内公众提供生成式 AI 服务」 | **是**（官网公开 + 登录注册 + 娱乐 C 端定位 + 语音通话）。注册默认关闭可部分缓解「公开运营」定性，但不能依赖 |
| 是否「具有舆论属性或社会动员能力」 | 从严口径**是**（聊天室/通讯群组被《安全评估规定》明确列举；无量化豁免线） |
| 是否命中《人工智能拟人化互动服务管理暂行办法》（2026-07-15 施行） | **娱乐陪伴模式很可能命中**——「持续性情感照护、陪伴、支持」即适用，需未成年人保护/安全评估/算法备案/2 小时提醒/反情感操纵专项义务 |
| 备案路径 | **算法备案（生成合成类）+ 大模型登记**（仅 API 调用 DeepSeek/豆包等已备案模型，未微调 → 登记而非备案）双轨并行，缺一不可。境外模型（Anthropic 官方端点）无法完成登记 |
| 现行执法 | 2026「清朗·整治 AI 应用乱象」把「应备未备」列为首要整治项；剪映/猫箱/即梦因**标识不落实**被约谈处罚；API 中转站被认定不得豁免 |

## 一、极高危（发布即违反现行法规，立即修）

### 1. GPLv3 代码被打进对外分发的 Agent exe
- **事实**：`build/yuanai_agent/PYZ-00.toc` 显示 `pymsgbox`、`mouseinfo`（GPL-3.0-or-later，pyautogui 传递依赖）被冻结进「小元AI Agent.exe」且未在 requirements.txt 声明。
- **影响**：exe 成为含 GPLv3 代码的组合作品，按 GPL 义务须提供完整对应源码并允许再分发——与闭源商业定位直接冲突。
- **修复**：`agent/yuanai_agent.spec` 加 `excludes=['pymsgbox','mouseinfo']`，重建后用 TOC 验证。

### 2. 全链路无 AI 生成内容标识（《标识办法》2025-09-01 起强制）
- **事实**：聊天文本气泡无「AI生成」标识（角色名不算）；TTS/语音通话无提示；落库无隐式标识字段；导出/下载无标识；知识星球 AI 笔记提示词**主动禁止**说明性前言；生图生视频（规划中）无标识基建。
- **法规**：《人工智能生成合成内容标识办法》第 4/5/8 条 + GB 45438-2025；深度合成规定第 17 条；生成式AI办法第 12 条。
- **2026-04 执法**：剪映、猫箱、即梦 AI 因标识不落实被约谈、责令改正、警告。
- **修复**：每条 AI 气泡固定「AI生成」徽标+文字提示（流式期间也可见）；复制/导出附显式标识；TTS 音频头尾提示音 + ID3 元数据；落库加 `aigc` 字段（Label/ContentProducer/ProduceID）；AI 笔记正文首行标识。

### 3. 对话/语音全链路零内容审核
- **事实**：`/stream`（工作/娱乐/云端回退）、本地 Agent 桥接、`/claude-stream`、语音 RTC LLM、`/voice/tts`（任意文本合成语音）均无输入/输出审核；无违法内容「停止生成/消除/记录/报告」机制；`agent/audit` 是题目审核，与对话内容安全无关。
- **法规**：生成式AI办法第 4/14 条；网安法第 49 条；生态治理规定第 9/10 条。
- **修复**：建统一内容安全网关（输入输出双向：关键词库+语义审核+人工复核队列+处置 SOP+审计日志）；TTS/语音通道同网。

### 4. 无隐私政策、无用户协议、无同意勾选
- **事实**：公开路由无 `/privacy`/`/terms`；注册/登录无 `agreed_terms` 字段、无勾选；页脚无协议入口、无 ICP 备案号展示；未披露第三方接收方（DeepSeek/豆包/火山/网关）；娱乐人设要求「不暴露记忆机制」与隐私透明义务直接冲突。
- **法规**：PIPL 第 17 条；生成式AI办法第 9 条；标识办法第 8 条；网安法第 26 条。
- **修复**：上线《用户协议》《隐私政策》《服务规则》（含第三方共享清单、保存期限、未成年人条款、AI 标识规范）；登录/注册前强制勾选并留存同意版本记录。

### 5. 无投诉举报机制
- **事实**：只有点赞/点踩，后端「只写不读」无处理页面；账号冻结无原因/证据/申诉入口/处理时限；每条 AI 消息无「举报」按钮；登录页只有个人微信邮箱。
- **法规**：生成式AI办法第 15 条；生态治理规定第 9/10 条。
- **修复**：消息级举报入口 + 工单系统 + 管理员处理页 + 公示处理流程与反馈时限；冻结附原因与申诉通道。

## 二、高危（安全越权 / 删除权 / 出境，尽快修）

### 6. Agent 记忆接口跨用户越权（IDOR）
`/agent/memory*` 只校验设备 secret 不校验设备↔用户绑定，任意注册设备传入他人 `user_id` 可读/写/整理/删他人长期记忆（api/v1/agent/router.py:206-214,480-559）。→ 改用 `require_agent_uid` 强制目标 user_id 等于设备绑定用户。

### 7. 聊天图片与私有知识库图片公开无鉴权
`/api/v1/chat/image`、`/api/v1/knowledge/img` 在公开路径白名单，仅路径校验；URL 泄露即永久可读（缓存 1 年）。→ 改鉴权路由或签名短链。

### 8. 删除权不完整
无用户自助注销；管理员删用户只删 `users` 行（全库无外键级联），消息/记忆/图片/数据集/星球/设备/日志/分析历史全部残留；会话删除不删磁盘图片；TOS 远端备份从不清理。→ 注销接口 + user_id 级联清理 + 备份保留期。

### 9. 数据出境链路口子
- Claude SDK 未配 `ANTHROPIC_BASE_URL` 时默认连 **Anthropic 官方境外端点**（无校验无告知）；
- 自定义模型默认回退 `api.openai.com`（境外）；
- 搜索兜底 DuckDuckGo、医学检索 NCBI（美国）——查询词可能含个人信息；
- 国内链路（DeepSeek/豆包/火山）不构成出境，但需披露委托处理。
→ 境内端点强制校验 + 出境开关 + 隐私政策披露 + 数据地图。

### 10. 未成年人保护缺失（娱乐陪伴模式首当其冲）
无年龄识别/未成年人模式/监护人同意/防沉迷；娱乐陪伴人设无适龄条款；语音陪伴无年龄门禁。**拟人化互动办法（2026-07-15）明确：不得向未成年人提供虚拟伴侣/虚拟亲密关系服务**。→ 年龄申报 + 未成年人模式 + 时长提醒 + 监护人通道。

### 11. 许可证义务与分发声明缺失
- pystray（LGPL-3.0）无许可文本、无可替换/重链接说明；exe 无任何 LICENSE/NOTICE；
- 仓库无 LICENSE（公开仓库默认「保留所有权利」）、无 EULA；
- dsh-pet 包缺 PySide6/Qt（LGPL）与 FFmpeg 许可文本；MIT 文本藏在 `_internal` 内；
- icons.tsx 疑似复用 Lucide/Feather path 无声明；plotly.min.js 只有横幅无全文。
→ `THIRD-PARTY-NOTICES.txt` 自动生成（pip-licenses + npm license-checker）+ 随 exe/zip/官网 `/licenses` 分发。

### 12. 爬虫合规缺口
- 全仓无 robots.txt 解析；多处伪装/随机 UA；`spiderlx/anti/cdp.py` 主动反检测；
- 通用采集脚本裸 `requests.get`：重定向/分页可绕过 SSRF 校验；浏览器 `open_custom_url` 无 URL 校验（内网/file 可达）；
- 预置小猿众包/知乎/BOSS直聘/B站自动化（可能违反目标平台用户协议）；Bing/DDG HTML 抓取兜底；
- 示例数据来源不明（RFM xlsx 第三方元数据、流失 CSV 疑似 Kaggle 数据集、`data/aiprompt` 15MB 疑似课程素材）。
→ robots 检查 + 统一可识别 UA + 按域名限流 + 采集记录附来源/robots 状态；高风险预置自动化下线或加用户确认；示例数据改合成数据。

### 13. 其他安全项
- `/chat/stream` 传 `target_agent=claude` 可绕过 `/claude-stream` 的白名单 → 桥接需同白名单；
- 客户端可提交 `system_prompt` 覆盖平台人设/安全指令 → 服务端固定 canonical system prompt；
- 管理员文件管理可读全部用户聊天图片/原始数据集（无审批无审计）；
- RFM 图表/dashboard-html 归属校验不一致；
- JWT 7 天 + localStorage；DB 故障时吊销检查 fail-open；个人内容明文存储（依赖基础设施层防护）。

## 三、中危（治理类，30-90 天）

- **保留期**：visit_log（IP/UA）、登录日志、聊天/图片、分析历史均无 TTL——建议 visit/登录日志 90 天、聊天可配置（默认 180 天或用户可删）；IP/UA 截断或哈希。
- **语音敏感个人信息**：声纹定性从严；需单独同意 + 保存期限 + 第三方披露 + 不用于训练。
- **备份策略**：TOS 远端备份永久保留与删除权冲突 → 设保留期（如 30 天）与删除同步机制。
- **PIA/DPA**：语音、未成年人、跨境、记忆画像场景做个人信息保护影响评估；与模型/语音/云供应商签数据处理协议（不训练、零留存、审计权）。
- **日志留存**：网络日志 6 个月（网安法 2026-01-01 施行）、标识去标日志 6 个月、委托处理记录 3 年。
