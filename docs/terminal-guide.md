# 本地终端使用说明书（2026-11-15 定版，随大方向更新）

小元AI 的本地形态 = **终端**。本说明书覆盖三个入口：CC 终端（主力）、yuan 终端（无凭证用户的本地终端）、托盘 Agent（后台执行体）。

**先看哪节（按人群对号入座）**：
- 只想装好就能用（不折腾任何配置）→ 直接看 **第 4 节托盘 Agent**（双击安装即完成）与 **第 3 节 yuan 终端**
- 有 DeepSeek API key、愿意折腾的进阶用户 → 第 2 节 CC 终端

## 1. 入口与定位

| 入口 | 定位 | 适用 |
|------|------|------|
| **CC 终端（claude + 小元AI MCP）** | 本机主力：对话/代码/终端/Git 原生能力 + 发现与调用本地智能体、跨系统执行 | 装了 Claude Code 的用户 |
| **yuan 终端** | 无凭证用户的本地终端（平台云端为模型层），可访问云端会话 | 无模型 key 的用户 |
| **托盘 Agent** | 后台执行体：接收网站任务、跑计划队列 | 开机常驻 |

> 大方向：网站/移动端是**唯一的主对话入口**（发指令 + 看进度）；本地=终端形态——**CC 终端是主形态**（有模型凭证的用户），yuan 是无凭证用户的本地终端（平台云端为模型层），不是网站的桌面客户端。

## 2. CC 终端（适合有模型 key 的进阶用户；普通用户请跳过本节）

### 2.1 安装 Claude Code 与接入小元AI MCP

**第一步（安装 Claude Code）**：按 DeepSeek 官方集成指南安装并配置：
https://api-docs.deepseek.com/zh-cn/quick_start/agent_integrations/claude_code

（用户自持 DeepSeek API key，费用直接与 DeepSeek 结算——按 Anthropic 2026-09
条款，平台不代付、不中介模型流量；普通用户无模型 key 时请用 yuan 终端。）

**第二步（接入小元AI MCP，一行命令）**——按你的安装形态二选一：

安装包用户（普通用户，零源码）：
```bash
claude mcp add xiaoyuan -- "C:\Users\<你的用户名>\AppData\Local\XiaoYuanAI\bin\小元AI Agent.exe" --run-mcp
```
（引号内换成你电脑上的安装路径；`claude mcp list` 看到 xiaoyuan ✔ Connected 即成功）

开发者（有项目源码）：
```bash
claude mcp add xiaoyuan -- venv\Scripts\python.exe -m agent.mcp_server
```

### 2.2 能干什么

- **发现**：直接问「看看本地有哪些智能体」——CC 会调用 `list_local_agents` 列出统筹/自动化/分析脚本/采集/桌宠状态
- **调用分析脚本**：直接说「用 RFM 分析客户分群」——CC 会调用 `script_rfm_cluster`（参数校验与网站对话同一套规则），脚本在本机跑
- **采集**：`script_generic_crawl` 网页采集
- **桌宠联动**：脚本执行时桌宠自动切工作/思考状态

### 2.3 注意事项

- 脚本产出的图表/看板会给出文件路径或看板 key（网站对话里可打开面板查看）
- 尚未接入（A2 规划中）：自动化浏览器、计划队列、记忆、知识星球检索、云端对话桥

## 3. yuan 终端（无凭证用户的本地终端）

### 3.1 启动（普通用户路径）

安装包用户：**右键右下角小元AI 托盘图标 → 「终端对话」**——直接打开终端，启动即接续 CC 窗口会话（与网站完全同步），不需要敲任何命令。

开发者（有项目源码）也可在命令行敲 `yuan` 直接启动。

### 3.2 窗口（三个）

| 命令 | 窗口 | 说明 |
|------|------|------|
| `/claude` | CC 窗口（默认） | 与网站 CC 窗口同一会话；执行时间线形态（扁平全宽 + 棕色左条） |
| `/chat` | 小元窗口 | 网站主对话，气泡形态 |
| `/local` | 本机直连 | Claude SDK 草稿会话，不与网站同步（开发者模式） |

### 3.3 命令

**终端内随时按 `?` 键弹出帮助浮层**（命令/按键一屏速查，不用记）：

```
/claude   CC 窗口         /chat     小元窗口
/local    本机直连         /new      新建会话（按当前窗口）
/sessions 会话列表/切换    /plan     计划队列（/plan <序号> 看步骤）
/status   本机状态         /panel    设置面板
/pet on|off 桌宠          /web      打开网站对话
/history  本机直连会话     /clear    清空显示
/help     帮助浮层         /quit     退出
```

### 3.4 按键

```
Enter 发送 · Esc+Enter 换行 · ↑↓ 选块 · Enter 展开/折叠
PgUp/PgDn 滚动 · End 回到底部 · Tab 补全命令
Ctrl+R 搜索历史（键入即过滤） · F2 网站对话
Ctrl+C / Ctrl+Q 生成中停止、空闲退出 · ? 帮助浮层
```

### 3.5 同步与执行可见

- **双向同步**：终端发的消息网站立即可见；网站发的消息终端 15 秒内自动出现
- **执行可见**：工具调用行（⚙ 工具名）+ 右栏执行观测（本机最近活动）+ 状态栏「本机执行/云端执行」
- **审批**：弹出小卡片——Y 执行 / N 拒绝（回车=拒绝，120 秒超时默认拒绝）
- **窗口徽标**：状态栏显示「CC 窗口 / 小元 / 本机直连」中文徽标

## 4. 托盘 Agent

- 双击安装后右下角出现小元AI 圆球图标 = 后台就绪（接收网站任务、跑计划队列）
- 右键菜单：账号归属、能力开关、设置面板、检查更新、终端对话、桌宠
- 网站任务流程：手机发指令 → 云端统筹 → 托盘 Agent 执行 → 手机看结果

## 5. 常见问题

| 问题 | 处理 |
|------|------|
| 我什么都不想配置，怎么用上终端 | 网页「本地 Agent」页下载 → 双击安装 → 右下角托盘图标 → 右键「终端对话」（yuan 内置在安装包里，零命令行零配置） |
| yuan 提示「未找到本机 Agent 身份」 | 网页登录后到「本地 Agent」页下载安装（自动注册） |
| CC 里看不到 xiaoyuan 工具 | `claude mcp list` 确认 ✔ Connected；未注册先 `claude mcp add` |
| 网站发的消息终端没出现 | 终端保持打开（15s 轮询）；检查本地后端/网络 |
| 图表想看大屏 | 脚本输出含看板 key——在网站对话中说「打开看板」或复制 key 到 /chat/agent/board/<key> |
| 生产环境同步不生效 | 需先部署（chat-token 端点 + 迁移 0031/0032/0033） |
